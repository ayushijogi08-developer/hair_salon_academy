# src/assets/images/transformations/

Place real, verified client before and after transformation photos here.
Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

## Strict Privacy & Consent Requirement:
> **Important:** Written client consent is strictly required before taking, storing, or publishing any client before/after photos. Ensure all clients have signed or agreed to media release terms for social/web presentation.

## File Naming Convention:
Pair each transformation with matching filenames for the "before" and "after" state:

- `ba-01-before.jpg`
- `ba-01-after.jpg`
- `ba-02-before.jpg`
- `ba-02-after.jpg`

## Photo Guidelines:
- **Consistent Framing & Angle:** Shoot both photos from the identical head/hair angle (e.g. direct back view, 45° profile, or direct front).
- **Matching Lighting:** Use the same salon lighting and chair position for both shots to showcase genuine hair texture and colour tonality.
- **Aspect Ratio:** 4:3 or 16:10 recommended (minimum 1200x900px, compressed under 500KB).
- **Verification:** Register each pair in `src/data/site.js` under `siteData.beforeAfter`. Keep `confirmed: false` until the salon owner approves the imagery.
